"오늘의 질문도 2단으로 해서 편집하는 창 오른쪽으로 빼줘. 오늘의 질문 편집 페이지에서는 텍스트에어리어에 테두리 꼭 둬줘."

  • 질문 관리(questionManage)가 미션 활동과 같은 .split 틀(.split-question). 왼쪽 강의 줄(n강 제목 + 켜고 끄는 눈 단추), 오른쪽 머리(n강 제목 + 저장)와 편집 칸(questionForm): 이름표 + 글 칸 한 줄씩, 질문 3줄, 설명문 10줄. 꺼진 강의는 "오늘의 질문이 꺼져 있습니다."
  • 편집 단추를 따로 누르지 않는다. 오른쪽 칸에서 바로 고치고 저장(q-save). 좁은 화면은 고른 줄 아래로 펼친다
  • 카드 펼침과 편집 모드(questionOpenId, questionEditId, q-open, q-edit-*)를 걷어내고 state.questionSel 하나로
  • 글 칸 테두리: .qform textarea.f에 --line-strong 테두리를 못박았다(포커스는 레드)
  • 캐시 admin.css?v=20261029x, admin.js?v=20261029t

표는 model.js의 STUDENT_VIEWS와 STUDENT_MENUS 한 곳에 있다. 메뉴를 더하고 빼려면 거기만 고친다. 조회는 getPartItems(courseId, partKey) 하나로 끝난다: 공개된 꽂힌 강의 중 그 칸을 가진 것만.

화면 상태가 view 하나에서 view + layout + menuKey로 늘었다. login / rooms / home / lesson / menu / part 여섯 화면이다.

3) 모바일과 PC가 같은 화면 (86)

교사는 PC와 모바일로, 학생은 폰과 패드로 들어온다. PC 전용 화면을 따로 만들지 않는다.

  • 기준을 폰에 두고 넓어지면 카드가 두 줄로 늘어난다(.grid, 640px)
  • 손으로 누르는 것은 44px 밑으로 내려가지 않게. 입력 칸 글씨는 16px 아래로 내리지 않는다 (사파리가 칸을 누를 때 화면을 확대해 버린다)
  • 어드민은 760px 밑에서 왼쪽 메뉴가 위쪽 가로 스크롤 줄로 바뀐다. 폼 줄도 쌓인다
  • 노치 대응(env(safe-area-inset-*))

4) 강의 슬라이드는 늘 새 탭 전체화면 (87): slide.html 새로

개념노트 칸에서 펼치지 않고 슬라이드 열기 버튼 하나만 둔다. 누르면 새 탭이 뜬다.

  • 쪽은 16:9를 화면 안에 꽉 채워 넣는다(잘리지 않게 min(100vw, 100vh*16/9))
  • 위쪽 막대는 평소 숨고 마우스를 올리거나 화면 위를 건드리면 나온다. 투사 중에 안 거슬리게
  • 전체화면은 버튼을 눌러야 들어간다: 브라우저가 자동 진입을 막는다. 전체화면에 들어간 뒤에만 screen.orientation.lock('landscape')이 먹어서 모바일 가로가 된다
  • 좌우 화살표, 스페이스, F(전체화면) 키로 조작
  • 아직 뼈대다: 쪽 내용이 없어 표지 한 장만 선다. 슬라이드 엔진은 방학 과제이고 slide-render.js, page-lesson.*이 그때 쓸 재료다
